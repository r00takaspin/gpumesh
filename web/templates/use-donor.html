Start Ollama
docker run -d --gpus all -p 11434:11434 --name ollama ollama/ollama
2
Pull a model
docker exec -it ollama ollama pull llama3.2:3b
3
Install provider
go install github.com/r00takaspin/gpumesh/cmd/provider@latest
4
Run
Paste the command above
Provider runs on host and connects to Ollama at localhost:11434. --gpus all requires nvidia-container-toolkit.
