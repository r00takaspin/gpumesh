About GPU Mesh

Share local Ollama models with friends or coworkers using a PIN. They get a stable URL for Cursor, Cline, Pi, curl, and similar tools.

Owner

Runs Ollama + provider, creates invites, revokes access.

Member

Enters a PIN once, then uses a base URL + API key in their tools.

Privacy: your prompts go through the GPU Mesh server and are visible to whoever runs the machine. We don’t store prompt content.

FAQ

Is the PIN one-time?

By default yes (1 use, 7 days). The owner can allow more uses or a longer expiry.

Is GitHub required?

Yes to join and manage invites. After that, tools use an API key.

How is this different from Tailscale?

This is only for LLM API access with invites and revoke — not a full VPN.

What if the machine is offline?

Requests fail with a clear offline error. We don’t silently switch to another machine.
