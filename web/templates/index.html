$ whatis gpumesh

GPU Mesh is a peer-to-peer network for free LLM inference. Thousands of enthusiasts worldwide share their idle GPUs, and the coordinator routes requests to available compute — no cloud bills, no rate limits.

$ whois gpumesh --audience

For the person downloading models from HuggingFace at 3 AM. For the Raspberry Pi owner with a GPU strapped to the balcony. For anyone who values "free" over "enterprise-grade". Enthusiasts. Community. Hobby projects.

$ cat HOW_IT_WORKS.txt | head -3

1. Volunteers run gpumesh-provider — a lightweight agent that registers their GPU with the mesh.
2. You send a request through any OpenAI-compatible tool (Aider, Cline, Continue.dev, curl, anything).
3. The coordinator finds a free GPU, proxies your request, streams back the response. No logs. No quotas.

FAQ
▶ Is it really free?
Yes. Community GPUs, community effort. No catches, no credit card, no usage caps.
▶ Is my data safe?
Prompts and responses are never stored on our servers. Donors see requests in transit to serve inference — the same as any API provider. No persistent logging.
▶ What models are available?
All Ollama-compatible models that donors have shared. Browse the full catalog at /models. Common picks: llama3.2, codellama, qwen2.5, mistral.
