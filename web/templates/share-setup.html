Install Ollama, pull a model, and run the provider on your GPU machine.

1. Install Ollama + pull a model

curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.2:3b
⚠ Ollama must be running (ollama serve) and reachable at localhost:11434. If running on a remote machine, set OLLAMA_HOST=0.0.0.0 and restart.

2. Install the provider

curl -sSfL https://gpumesh.net/install-provider.sh | sh
